# Changelog

## 3.0.1

### Changed

- Supports PHP 8.1 again, like Magento 2.4.6: the Adobe Commerce Marketplace requires modules to allow every PHP
  version of the Magento versions they support.

## 3.0.0

### Breaking changes

- Requires Magento 2.4.6 or newer and PHP 8.2 or newer. Magento 2.4.4 and 2.4.5 and PHP 7.1 to 8.1 are no longer
  supported; use version 2.x for these.
- Requires `infrangible/m2-task` 3.0, `infrangible/m2-backend-widget` 4.0, `infrangible/m2-core` 5.0,
  `infrangible/m2-foundation` 3.0, `infrangible/m2-simple-mail` 2.0 and `fewedev/base` 2.4. m2-core 5.0.4 fixes the
  product data, which the sitemap of products needs.
- All classes have native types, and the constructors use constructor property promotion. Changed constructors: the
  task (`Task\Sitemap`, with the new constructor of m2-task 3.0 and the writer), the sources, the sitemap helper, the
  collection and the store column of the list. The interfaces of sources and sitemap URLs and the events are
  unchanged.
- The sitemap files are written by `Model\Writer`; the task no longer has the methods that wrote them.
- The column and the attributes "Exclude from Sitemap" are created by declarative schema (`db_schema.xml`) and a data
  patch instead of install scripts.

### Fixed

- The sitemap can be generated with Magento 2.4.8 and newer; with m2-task 2, the installation of Magento failed with a
  fatal error.
- The index of a sitemap that is split into several files links the files with their URLs; before, it contained their
  paths on the server.
- URLs use HTTPS if the store uses it in the frontend; before, sitemaps that were generated by cron or on the console
  had HTTP URLs.
- Every file uses the base URL of its stores; before, the files of all stores used the URL of the store of the run.
- Inactive CMS pages are no longer in the sitemap.
- The home page and the 404 page of every store are recognized, also if the configuration refers to them with
  "identifier|page ID"; before, only those of the default configuration were.
- Entries without date of the last change have no date; before, they had 1970-01-01. Values that are not set are left
  out instead of written as empty elements.
- Products without gallery images and entities without URL no longer cause warnings or wrong URLs.
- The emulation of the store ends when a source fails.
- The category attribute "Exclude from Sitemap" is added to the attribute sets of categories; before, the install
  script looked for it in the product attributes.
- File names with directories (for example `sitemap/de.xml`) create the directory; file names outside the document
  root are rejected.
- A store may use `sitemap.xml` if the main sitemap is switched off; before, several files were not possible then.
- The store names in the list of files are escaped.

### Added

- Validation of the priority (0.0 to 1.0) and comments in the configuration.
- `Infrangible\Sitemap\Helper\Data` provides URLs, dates, change frequency and priority for sources of other modules.
- Translations into 24 locales.
- README.

### Changed

- The module is loaded after the Infrangible modules and the Magento modules it uses.
- Checks with PHPStan level 9, the Magento coding standard and unit tests on every push.
